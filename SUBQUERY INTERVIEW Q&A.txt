SQL Subqueries – Technical Interview Questions
1. What is a Subquery in SQL? Why is it also called an Inner Query or Nested Query?
Answer

A Subquery is a query written inside another SQL query.

The inner query executes first.
Its result is passed to the outer query.
The outer query uses that result to produce the final output.

It is also called:

Inner Query because it is written inside another query.
Nested Query because one query is nested within another.
Example
SELECT Employee_Name
FROM Employee
WHERE Salary >
(
    SELECT AVG(Salary)
    FROM Employee
);

The inner query calculates the average salary.

The outer query displays employees earning more than the average salary.

2. What are the different types of Subqueries in SQL?
Answer

There are five major types.

1. Single Row Subquery

Returns only one row.

Example:

SELECT *
FROM Employee
WHERE Salary >
(
    SELECT AVG(Salary)
    FROM Employee
);
2. Multiple Row Subquery

Returns multiple rows.

Example:

SELECT *
FROM Employee
WHERE Department_ID IN
(
    SELECT Department_ID
    FROM Department
);
3. Correlated Subquery

Depends on the outer query.

Executed once for every row.

Example:

SELECT Employee_Name
FROM Employee E
WHERE Salary >
(
    SELECT AVG(Salary)
    FROM Employee
    WHERE Department_ID = E.Department_ID
);
4. Multiple Column Subquery

Returns more than one column.

Example

SELECT *
FROM Employee
WHERE (Department_ID, Salary) IN
(
    SELECT Department_ID, MAX(Salary)
    FROM Employee
    GROUP BY Department_ID
);
5. Nested Subquery

A subquery inside another subquery.

Example

SELECT *
FROM Employee
WHERE Department_ID =
(
    SELECT Department_ID
    FROM Department
    WHERE Location =
    (
        SELECT Location
        FROM Branch
        WHERE Branch_ID = 1
    )
);

5. What is a Correlated Subquery? How is it different from a Normal Subquery?
Normal Subquery

Runs once.

Its result is used by the outer query.

Example

SELECT *
FROM Employee
WHERE Salary >
(
SELECT AVG(Salary)
FROM Employee
);
Correlated Subquery

Runs once for every row in the outer query.

Example

SELECT Employee_Name
FROM Employee E
WHERE Salary >
(
SELECT AVG(Salary)
FROM Employee
WHERE Department_ID = E.Department_ID
);
Difference
Normal	Correlated
Runs once	Runs for every row
Independent	Depends on outer query
Usually faster	Usually slower
6. What is a Multiple Column Subquery? When is it used?

Returns two or more columns.

Useful when comparing multiple columns simultaneously.

Example

SELECT *
FROM Employee
WHERE (Department_ID, Salary) IN
(
SELECT Department_ID,
MAX(Salary)
FROM Employee
GROUP BY Department_ID
);

Use cases

Highest salary in each department
Latest order per customer
Employee with maximum salary by branch
7. What is a Nested Subquery? How does SQL execute it?

A Nested Subquery contains another subquery.

Execution starts from the innermost query.

Example

FROM Employee
WHERE Department_ID =
(
SELECT Department_ID
FROM Department
WHERE Location =
(
SELECT Location
FROM Branch
WHERE Branch_ID=1
)
);

Execution

Branch query
Department query
Employee query

11. What error occurs if a Single Row Subquery returns more than one row?

Error:

Subquery returns more than one row

Example

SELECT *
FROM Employee
WHERE Department_ID=
(
SELECT Department_ID
FROM Department
);

If multiple department IDs are returned, SQL raises an error because = expects only one value.

12. Difference between IN and EXISTS
IN	EXISTS
Compares values	Checks whether rows exist
Suitable for small result sets	Better for large result sets
Returns all matching values	Stops after finding the first match
Can be slower on large data	Often faster with correlated subqueries

Example using IN

SELECT *
FROM Employee
WHERE Department_ID IN
(
SELECT Department_ID
FROM Department
);

Example using EXISTS

SELECT *
FROM Employee E
WHERE EXISTS
(
SELECT 1
FROM Department D
WHERE D.Department_ID = E.Department_ID
);

Yes.

SELECT Department_ID
FROM Department

(
SELECT Location
FROM Branch
WHERE Branch_ID=1
)

14. How many levels of Nested Subqueries are allowed?

It depends on the database system.

MySQL: Supports multiple levels; practical limits depend on query complexity and server resources.
SQL Server: Up to 32 levels of nesting.
Oracle: Supports many levels, with practical limits based on memory and optimization.
PostgreSQL: Supports deep nesting; practical limits depend on available resources.

In practice, avoid excessive nesting because it reduces readability and can hurt performance.

15. Common real-time business scenarios where Subqueries are preferred over JOINs
Find employees earning more than the company average salary.
Find customers who placed orders in the last month.
Identify products never sold.
Find departments with above-average salary.
Retrieve customers with the highest purchase amount.
Delete duplicate records while keeping one copy.
Update salaries based on department averages.
Filter orders above the average order value.
Identify inactive users with no transactions.
Insert top-performing employees into a bonus table.
Interview Tip

If you're asked "Subquery or JOIN—which is better?", a good answer is:

Use a Subquery when the result of one query is needed to filter or calculate another query, especially for scalar values like averages, maximums, or existence checks.
Use a JOIN when combining data from multiple tables, especially for reporting and large datasets, because it is often easier to optimize and can perform better.
