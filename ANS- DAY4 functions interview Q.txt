        on data and returns a value.

-- 5.What is a Single Row Function (Scalar Function)?
    A Single Row Function (also called a Scalar Function) is an SQL function that operates
      on one row at a time and returns one value for each row.
    These functions are used to manipulate or transform data such as text, numbers, dates, and data types.
          Characteristics of Single Row Functions
              1.Operate on individual rows.
              2.Return one result for each row.
              3.Can accept one or more arguments.
              4.Can be used in the SELECT, WHERE, ORDER BY, and GROUP BY clauses.
              
Types of Single Row Functions
String Functions – UPPER(), LOWER(), LENGTH(), SUBSTRING()
Numeric Functions – ROUND(), ABS(), CEILING(), FLOOR()
Date Functions – CURRENT_DATE, NOW(), YEAR(), MONTH()
Conversion Functions – CAST(), CONVERT()
             Advantages of Single Row Functions
			- Simplify SQL queries.
			-Improve data formatting and presentation.
			- Perform calculations on individual values.
			- Reduce repetitive code.
             - Make queries easier to read and maintain.


A Single Row Function (Scalar Function) is an SQL function that processes one row at a time

 -- 13. What is the purpose of the INSTR() function?
    
              The INSTR() function is an SQL Character (String) Function used to find the position of a specified substring within a string.
              It returns the starting position (index number) of the first occurrence of the searched character or substring. 
              If the substring is not found, it returns 0 (in many SQL databases such as Oracle).
syntax:
INSTR(string, substring)
string → The original string to search.
substring → The character or text to find.

example:
SELECT INSTR('Database', 'base'); o/p-> 5
Explanation:
In the word "Database", the substring "base" starts at the 5th position

Uses of INSTR()
Find the location of a character or word inside a string.
Validate whether a string contains specific text.
Extract parts of a string when combined with functions like SUBSTRING().


 --  14. What is the difference between ROUND(), CEIL(), and FLOOR()?

         The ROUND(), CEIL(), and FLOOR() functions are SQL Numeric Functions used to modify numeric values

| **Function**               | **Purpose**                                                                        | **Example**    | **Output** |
| -------------------------- | ---------------------------------------------------------------------------------- | -------------- | ---------- |
| **`ROUND()`**              | Rounds a number to the nearest value based on decimal places.                      | `ROUND(12.56)` | `13`       |
| **`CEIL()` / `CEILING()`** | Returns the smallest integer greater than or equal to a number (always rounds up). | `CEIL(12.56)`  | `13`       |
| **`FLOOR()`**              | Returns the largest integer less than or equal to a number (always rounds down).   | `FLOOR(12.56)` | `12`       |

round:SELECT ROUND(15.678, 2);  o/p->15.68
ceil  :SELECT CEIL(15.2);  o/p->16
floor: SELECT FLOOR(15.9);   o/p->15

Key Difference
ROUND() → Rounds to the nearest value.
CEIL() → Always rounds up to the next integer.
FLOOR() → Always rounds down to the previous integer.

 -- 19. What is the difference between DATE_ADD() and DATEDIFF()?

| **Function**     | **Purpose**                                  | **Returns**                  |
| ---------------- | -------------------------------------------- | ---------------------------- |
| **`DATE_ADD()`** | Adds a specified time interval to a date.    | A new date value             |
| **`DATEDIFF()`** | Calculates the difference between two dates. | Number of days between dates |


1. DATE_ADD() Function

Used to add days, months, years, or other intervals to a date.

Syntax:

DATE_ADD(date, INTERVAL value unit)

Example:

SELECT DATE_ADD('2026-07-09', INTERVAL 10 DAY);

Output:

2026-07-19

(10 days are added to the given date.)
Real-time example:
Calculating a customer's subscription expiry date by adding the subscription period to the start date.

2. DATEDIFF() Function

Used to find the number of days between two dates.

Syntax:

DATEDIFF(date1, date2)

Example:

SELECT DATEDIFF('2026-07-19', '2026-07-09');

Output:

10

(There are 10 days between the two dates.)

Real-time example:
Calculating the number of days an employee has worked or the number of days between an order date and delivery date.

Key Difference:
DATE_ADD() → Adds an interval to a date and returns a new date.
DATEDIFF() → Finds the difference between two dates and returns the number of days.

Answer:

DATE_ADD() is used to add a specified interval (days, months, years, etc.) to a date, 
whereas DATEDIFF() is used to calculate the number of days between two dates.

-- 20. What is the difference between CAST() and CONVERT()?

      | **CAST()**                                                          | **CONVERT()**                                                                                                                              |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Converts a value from one data type to another.                     | Also converts a value from one data type to another, but provides additional formatting options in some databases (especially SQL Server). |
| Follows the SQL standard and is supported by most database systems. | Database-specific syntax and features may vary.                                                                                            |
| Syntax is simpler.                                                  | Often used for data formatting, especially with dates.                                                                                     |

CAST() and CONVERT() are used to convert data from one data type to another. CAST() is a standard SQL function, while CONVERT() 
is database-specific and often provides additional formatting features, especially for date and time conversions.

1. CAST() Function
Syntax:
CAST(expression AS data_type)

Example:
SELECT CAST('100' AS INT);
Output:
100

The string value '100' is converted into an integer.

2. CONVERT() Function
Syntax (SQL Server):
CONVERT(data_type, expression)

Example:
SELECT CONVERT(INT, '100');
Output:
100

 -- 21. What is the purpose of the IFNULL() function?

      The IFNULL() function is used to replace NULL values with a specified value. 
If the expression is not NULL, it returns the original value; otherwise, it returns the replacement value.

syntax:
IFNULL(expression, replacement_value)
expression → The value or column to check.
replacement_value → The value to return if the expression is NULL.
Example
SELECT IFNULL(NULL, 'No Data'); o/p-> no data

example:
SELECT employee_name,
       IFNULL(bonus, 0) AS bonus_amount
FROM employees;

 -- 22. What is the difference between IFNULL() and COALESCE()?
         
             IFNULL() accepts two arguments and replaces a NULL value with a specified value, 
whereas COALESCE() accepts multiple arguments and returns the first non-NULL value. COALESCE() is a standard SQL function, while IFNULL() is database-specific.

| **IFNULL()**                                               | **COALESCE()**                                                   |
| ---------------------------------------------------------- | ---------------------------------------------------------------- |
| Checks only **one value** and replaces it if it is `NULL`. | Checks **multiple values** and returns the first non-NULL value. |
| Takes **two arguments** only.                              | Can take **two or more arguments**.                              |
| Database-specific function (commonly used in MySQL).       | Standard SQL function supported by most databases.               |


syntax:IFNULL(expression, replacement_value
example:SELECT IFNULL(NULL, 'No Value');o/p->No Value

COALESCE:

SYNTAX:COALESCE(value1, value2, value3, ...)
EXAMPLE:SELECT COALESCE(NULL, NULL, 'Default Value');O/P->DEFAULT VALUES

-- 24. How does the IF() function work in SQL?

             The IF() function is used to perform conditional operations in SQL. It returns one value when the condition is true and
 another value when the condition is false.

Syntax (MySQL)

IF(condition, value_if_true, value_if_false)

condition → The condition to check.
value_if_true → Value returned when the condition is true.
value_if_false → Value returned when the condition is false.


Example:

SELECT IF(10 > 5, 'True', 'False');

Output: True

Real-Time Uses of IF()
Categorizing data (High/Low, Pass/Fail, Active/Inactive).
Displaying different values based on conditions.
Creating simple conditional logic in queries.
